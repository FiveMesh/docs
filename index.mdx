FiveMesh is a cloud infrastructure platform for FiveM servers, powered by sCloud.

Use these docs to configure your workspace, register servers, prepare public asset delivery with FiveMesh CDN, enable resource download caching with FiveMesh Cache, run managed PMA-Voice compatible infrastructure with FiveMesh Voice and collect server events with FiveMesh Logs.

## What FiveMesh manages

- **FiveMesh CDN** hosts public server assets such as inventory images, phone media, loading screen files and other files that need stable public URLs.
- **FiveMesh Cache** proxies FiveM resource downloads through a cache URL generated for each registered server.
- **FiveMesh Voice** runs managed PMA-Voice compatible infrastructure for registered servers.
- **FiveMesh Logs** collects server events for search, analytics and staff review.
- **Workspaces** select your own account or collaboration on an organization's owner account.
- **API keys** let scripts and tools access service operations with scoped permissions.

## Product paths

| Area | Use it for |
| --- | --- |
| **Dashboard** | Workspace overview, billing, organizations and account settings. |
| **CDN** | Public asset hosting, uploads, folders, previews, deletes and retention. |

Use the dashboard's support links for Discord and service status. If you are documenting an issue for support, include the workspace type, service area, server ID when relevant, and the action that failed.
