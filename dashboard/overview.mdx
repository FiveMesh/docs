Open the [FiveMesh dashboard](https://app.fivemesh.io) to manage your services, servers, usage and access.

Your account owns your subscription and resources. An organization lets your team collaborate on the owner's resources; it is optional.

## Main areas

| Area | What it contains |
| --- | --- |
| **Overview** | Service state, usage, billing status and next actions. |
| **Servers** | Registered cfx.re servers, server details and Server API Keys. |
| **Organization** | Optional team membership, invitations, roles, server access and service sharing. |
| **Billing** | Your own subscription, invoices, allowances and usage estimates. |
| **Delivery** | FiveMesh CDN and FiveMesh Cache. |
| **Realtime** | FiveMesh Voice. |
| **Observability** | FiveMesh Logs. |
| **Agent** | FiveMesh Agent when enabled in your account preferences. |

Open the user menu at the bottom of the sidebar and choose **Profile** for personal account settings. Notifications are available from the dashboard notification control.

## Account and server selection

The selector at the top of the sidebar shows the selected server and account context. Open it to choose **My account** or an organization, then select a server.

- **CDN** applies to the resource owner's whole account. Changing the selected server does not create another CDN workspace.
- **Cache**, **Voice** and **Logs** follow the selected server. Their pages use `/servers/{serverId}/cache`, `/servers/{serverId}/voice` and `/servers/{serverId}/logs`.
- **Billing** always manages your own customer subscription. Organization membership does not give you control over another customer's billing.

The `{serverId}` in a dashboard route is the FiveMesh registered-server ID. Use the cfx.re join code only where a setup field or public API explicitly requests it.

<Tip>
  Before changing service settings, check both the account or organization and the server shown in the selector.
</Tip>

## Service states

| State | Meaning |
| --- | --- |
| Subscription required | The resource owner's subscription does not currently allow the service. |
| Inactive or setup required | The service has not been enabled or configured yet. |
| Provisioning | FiveMesh is preparing the service. Wait for completion before using it. |
| Read-only or unavailable | Your role, service sharing or server access does not allow the action. |
| Ready | The service is configured and available. |
| Failed | Review the visible error and use the retry action when offered. |
| Deleting | Cleanup is in progress. Public service access may already be stopped. |

You can sign in and open Overview without a subscription, server or organization. Activate a plan before setting up services.
