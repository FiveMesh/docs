Voice setup and lifecycle operations currently use the dashboard. There are no documented public REST endpoints for creating, restarting or deleting instances.

A Voice permission on a Developer API Key does not make a dashboard route a supported public endpoint.

Select the registered server in the dashboard sidebar, then open **Voice** to activate the service, choose a region or operate its instance.
