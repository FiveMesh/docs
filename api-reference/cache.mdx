Cache setup and lifecycle operations currently use the dashboard. There are no documented public REST endpoints for enabling Cache, changing its origin, rotating the adhesive key, purging or preloading resources.

A Cache permission on a Developer API Key does not make a dashboard route a supported public endpoint.

Select the registered server in the dashboard sidebar, then open **Cache**. Copy the generated `fileserver_add` and `adhesive_cdnKey` block for your FiveM server.
