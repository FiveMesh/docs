FiveMesh is an official Quasar partner. Starting with **Quasar Phone v3.1.45**, Quasar Phone (also known as `qs-smartphone` or Quasar Smartphone) includes a built-in FiveMesh integration for phone media uploads.

Configure your FiveMesh API key in the phone's server-side `_G.fivemesh` block to use FiveMesh CDN for camera images, video recordings and voice recordings.

## Prerequisites

- Complete [FiveMesh CDN setup](/cdn/setup) for the active workspace.
- Install **Quasar Phone v3.1.45 or later**. Earlier versions do not include the native FiveMesh integration.
- Have access to the phone's server files and either a Server API Key or a Developer API Key with `cdn:write` permission.

## Configure FiveMesh

<Steps>
  <Step title="Create an API key">
    Quasar Phone supports both key types. In the [FiveMesh dashboard](https://app.fivemesh.io), choose either:

    - **Server API Key** (`fm_server_...`): Open **Servers**, select your registered server, then click **Generate API key** under **Server API Key**. CDN write access is included.
    - **Developer API Key** (`fm_live_...`): Open **Developers** → **API Keys** ([`/developers/api-keys`](https://app.fivemesh.io/developers/api-keys)). Create a key named `Quasar Phone` with `cdn:write` permission. Use this option when you need restricted CDN path access.

    Copy the secret. Either key can be used as the `token` in the next step. See [API keys](/account/api-keys) for the full workflow.

    If you restrict a Developer API Key to CDN path prefixes, confirm that they match the upload paths used by your installed phone version. A Server API Key's server binding does not restrict CDN paths.

  </Step>

  <Step title="Set the server-side token">
    Make sure your Quasar Phone resource is running **v3.1.45 or later**.

    Open the phone's `server/webhook.lua` file. Quasar's [installation guide](https://www.quasar-store.com/docs/smartphone/installation#fivemanage-api-setup) uses the resource path `qs-smartphone/server/webhook.lua`; use your installed resource folder name.

    Find the existing `_G.fivemesh` block and replace its `token` value with your FiveMesh API key:

    ```lua
    _G.fivemesh = {
        token = 'YOUR_FIVEMESH_API_KEY'
    }
    ```

    Preserve any other settings in the existing block. If `_G.fivemesh` is missing, verify that your installed Quasar Phone version is **3.1.45 or newer**.

    Keep the API key in server-side configuration. Do not place it in client Lua or the phone's web files.

  </Step>

  <Step title="Restart the phone">
    Save the file and restart the phone resource or your server to apply the change.
  </Step>
</Steps>

## Verify uploads

Take a photo, record a short video and create a voice recording in the phone. Check that each upload appears in the FiveMesh [object browser](/cdn/object-browser), then open or play the media in the phone.

## Troubleshooting

- **The FiveMesh block is missing:** Check that you're using Quasar Phone **v3.1.45 or later**. Older versions do not support native FiveMesh uploads. If the block is still missing after updating, contact Quasar support.
- **Uploads fail:** Check that the token is a FiveMesh API key with `cdn:write`, CDN provisioning has completed, and any key path restrictions allow the phone's upload paths. Check the server console for upload errors.
- **Uploads still use another provider:** Confirm that you edited `_G.fivemesh` in the running resource. Check your version's upload provider settings with Quasar.
