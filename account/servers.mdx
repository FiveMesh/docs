Registered servers connect your FiveM server identity to your FiveMesh customer account.

CDN works without a registered server. Cache, Voice and Logs require one. Organizations can give members access to the owner's servers.

## Find your cfx.re join code

Copy the short code from your server's Cfx.re join link. For example, `https://cfx.re/join/57gk77` has the code `57gk77`.

This is not the server license key or IP address.

## Register a server

<Steps>
  <Step title="Open Servers">
    Open **Servers** from the dashboard sidebar.
  </Step>
  <Step title="Add the join code">
    Choose the registration action, paste the cfx.re join code and submit the form.
  </Step>
  <Step title="Review detected details">
    Review the detected server name, origin, player slots and resource information when available.
  </Step>
  <Step title="Open the server">
    Select its row to open the server overview. Generate its [Server API Key](/account/api-keys#server-api-key) if you use the SDK or Logs viewer.
  </Step>
</Steps>

## Select a server for services

Use the selector at the top of the sidebar. Cache, Voice and Logs follow that server. Selecting a server does not switch CDN workspaces or change your billing ownership.

Dashboard routes use FiveMesh's registered-server ID. Public Logs ingestion and `FIVEMESH_SERVER_ID` use the cfx.re join code instead.

## Limits and access

Registration follows the resource owner's active plan allowance. If registration is unavailable, check subscription access, the server limit and your organization role.

If a registered server is missing in organization context, ask the owner to check your role and **Server access** grants.

## Edit or remove a server

Use the server management controls to edit its settings or remove it. Review the confirmation before deletion.

<Warning>
  Removing a registered server removes its bound credentials and disables Logs ingestion. It does not automatically delete independently managed Cache or Voice services. Review and remove those services first when they are no longer needed, then update your FiveM server configuration. Cfx.re itself is unchanged.
</Warning>
